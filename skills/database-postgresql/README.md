# Database — PostgreSQL

PostgreSQL *database* concepts: indexing strategies, advanced SQL, partitioning, security (RLS, pgcrypto, SSL/TLS), JSON/JSONB, and performance tuning — engine-level, not tied to Python.

For projects using PostgreSQL as their primary datastore. Pair with `python-postgresql` for the Python ORM/migrations layer.

## Install

```bash
npx skills add mihailtd/skills/skills/database-postgresql --all
```

Add `-g` to install globally instead of per-project. Use `--skill <name>` (repeatable) instead of `--all` to cherry-pick individual skills from this package, e.g.:

```bash
npx skills add mihailtd/skills/skills/database-postgresql --skill database-postgresql-advanced-sql-development
```
