# Database — General

Cross-database fundamentals that apply regardless of which engine (relational, document, etc.) a project uses.

## Install

```bash
npx skills add mihailtd/skills/skills/database-general --all
```

Add `-g` to install globally instead of per-project. Use `--skill <name>` (repeatable) instead of `--all` to cherry-pick individual skills from this package, e.g.:

```bash
npx skills add mihailtd/skills/skills/database-general --skill general-databases
```

## Skills (1)

- **[general-databases](general-databases/SKILL.md)** — Guides the agent on general database architecture, data persistence patterns, storage vs cache tradeoffs, and how to choose the right data platform.
