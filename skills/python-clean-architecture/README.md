# Python — Clean Architecture

Clean Architecture / Onion Architecture for Python, implemented in this repo's functional-lite style: pure functions over immutable dataclasses (Functional Core), a thin outer layer of plain functions for I/O (Imperative Shell), and the Dependency Rule enforced through layer packages rather than class hierarchies. Never OOP classes with methods for business logic — reformulate any class-based reference material before applying it.

Pair with `python-core` (functional-lite house style, fitness-function testing).

## Install

```bash
npx skills add mihailtd/skills/skills/python-clean-architecture --all
```

Add `-g` to install globally instead of per-project. Use `--skill <name>` (repeatable) instead of `--all` to cherry-pick individual skills from this package, e.g.:

```bash
npx skills add mihailtd/skills/skills/python-clean-architecture --skill python-clean-architecture-dependency-rule
```
